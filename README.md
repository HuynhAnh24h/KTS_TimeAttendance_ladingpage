# KTS TimeAttendance - Online License Portal & Landing Page (MERN Stack)

Hệ thống Website Landing Page giới thiệu phần mềm và Cổng quản lý bản quyền trực tuyến cho **KTS TimeAttendance**.

## Cấu trúc thư mục:
- `client/`: Giao diện React SPA (Vite + TailwindCSS + Lucide Icons)
- `server/`: Backend API Node.js + Express + MongoDB (Mongoose) + Thuật toán sinh License Key HMAC-SHA256
- `.github/workflows/`: CI/CD tự động kiểm thử và deploy
- `render.yaml`: Cấu hình 1-Click Free Deploy trên Render.com

Chi tiết hướng dẫn cài đặt và deploy miễn phí 100%, vui lòng xem file [HUONG_DAN_DEPLOY_FREE_CICD.md](./HUONG_DAN_DEPLOY_FREE_CICD.md).
